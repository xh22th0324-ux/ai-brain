## 一、十三辙全表

十三辙是北方曲艺、戏曲和现代流行歌写词最常用的押韵系统。按韵母归并成十三个「辙」。

| # | 辙名 | 韵母 | 例字 | 开口度 | 听感 | 推荐位置 |
|---|---|---|---|---|---|---|
| 1 | **发花** | a / ia / ua | 花、家、沙、茶、他、夸、下、话、怕、大 | ★★★★★ | 最明亮、外放 | **副歌**、呼喊 |
| 2 | **梭波** | o / e / uo | 河、多、说、我、过、火、破、歌、错、磨 | ★★★☆ | 平实、口语化 | 主歌、叙述 |
| 3 | **乜斜** | ie / üe | 别、夜、月、雪、写、解、烈、灭、节、铁 | ★★ | 窄、轻、脆 | 过渡句 |
| 4 | **一七** | i / ü / er（含 zhi chi shi ri zi ci si） | 里、起、你、时、事、日、知、子、词、思、雨、去 | ★★ | 细、闭口、内敛 | **主歌**、内心戏 |
| 5 | **姑苏** | u | 路、故、书、孤、无、苦、度、暮、素 | ★ | 最闷、收口 | 主歌、压抑 |
| 6 | **怀来** | ai / uai | 来、开、白、海、爱、快、怀、台、再 | ★★★★ | 开阔、上扬 | 中段、期待 |
| 7 | **灰堆** | ei / ui | 飞、回、谁、美、泪、归、水、醉、碎 | ★★ | 半闭、惆怅 | 主歌、叹息 |
| 8 | **遥条** | ao / iao | 好、少、笑、道、老、小、高、了、飘、遥 | ★★★★★ | 响亮、开朗 | **副歌**、明快 |
| 9 | **由求** | ou / iu | 秋、留、头、后、愁、酒、走、又、手、流 | ★★☆ | 沉吟、婉转 | 主歌、感伤 |
| 10 | **言前** | an / ian / uan / üan | 天、年、山、远、前、见、间、全、边、言、安 | ★★★★ | 鼻音、饱满 | **万能**，主副歌皆可 |
| 11 | **人辰** | en / in / un / ün | 人、心、春、深、真、分、云、门、痕、问 | ★★★ | 鼻音、含蓄 | 主歌、抒情 |
| 12 | **江阳** | ang / iang / uang | 长、光、望、江、上、乡、唱、凉、苍、浪 | ★★★★★ | 最响亮、共鸣强 | **副歌高潮**、气势 |
| 13 | **中东** | eng / ing / ong / iong | 风、生、梦、情、声、城、空、行、明、重 | ★★★★ | 浑厚、回荡 | 副歌、雄壮 |

### 选辙速查

```
开口大、最响亮：江阳(ang) > 遥条(ao) > 发花(a) > 中东(eng/ong)
鼻音带共鸣  ：言前(an) / 人辰(en) / 江阳(ang) / 中东(eng)
内敛往下沉  ：姑苏(u) / 一七(i) / 灰堆(ei) / 由求(ou)

副歌 → 选左边（响亮、能发力）
主歌 → 选右边（内敛、立得住）
万能 → 言前辙（-an），新手推荐，字量最大
```

### 三条选辙铁律

1. **副歌往上走** —— 副歌的辙要比主歌更开口。副歌用内敛辙，情绪推不上去。
2. **主歌往下沉** —— 主歌用响亮辙，会把副歌的气势提前透支。
3. **别全篇一个辙** —— 主歌一副韵 + 副歌一主韵，层次自然拉开。单辙到底容易单调，也容易硬凑。

### 关于混押

- **严格标准**：一辙到底，不混。
- **宽韵**：部分北方戏歌允许**邻辙通押**（如一七与灰堆、言前与人辰、江阳与中东）。
  **前提是全篇一致** —— 不能这一段混、下一段不混。
- 拿不准就**不混**。混押带来的那点便利，抵不上「听起来像跑韵」的风险。

> 另有《中华新韵》十四韵体系，用于格律诗词创作。写流行歌词用十三辙就够了。

## 二、字数与乐句对齐

**这一节回答一个问题：为什么是 7~12 字。**

### 推导过程

| 项 | 值 |
|---|---|
| 常规流行歌拍号 | 4/4 拍（一小节 4 拍） |
| 常规乐句长度 | 4 小节 = **16 拍** |
| 若一字一拍 | 16 字 —— 太密，几乎没有换气和拖腔空间 |
| 若一字两拍 | 8 字 —— 舒适，但偏慢 |
| **实际区间** | **每字占 1.3~2.3 拍 → 7~12 字** |

**所以「7~12 字」不是拍脑袋，是 16 拍的乐句里给拖腔和换气留出空间的必然结果。**

### 分段字数标准

| 位置 | 建议字数 | 理由 |
|---|---|---|
| 主歌每行 | 7~12 字 | 叙事容量够，一口气唱得完 |
| 预副歌每行 | 6~10 字 | 蓄力，字要少、气要足 |
| **副歌每行** | **5~10 字** | 短、好记、好发力 |
| **钩子句** | **5~8 字** | 越短越容易被记住、被复述 |
| 桥段每行 | 7~12 字 | 换视角，可以稍长 |

### 两条操作规则

1. **同段内各行字数尽量整齐**，允许 ±2 字浮动。
   > 相邻两行字数差超过 4 字，作曲时必然要删字或加字 —— **那是在最难改的地方改结构**。

2. **写完把每行字数标在右边。**
   > 这一步不能省。标出来，异类句子一眼就现形。

### 关于「破格」

**真人写词会有意让一两行字数和别的不一样**，制造节奏变化。

**全篇每行都等长，音乐性反而死了** —— 听起来像快板或顺口溜，不像歌。

> 规则是：**有意识的破格是技巧，无意识的字数崩坏是事故。**
> 前者你清楚为什么这么写，后者你只是没数。

## 三、韵脚布局

### 押韵密度

| 密度 | 效果 | 建议 |
|---|---|---|
| 每句都押 | 太密，像顺口溜、快板 | 慎用 |
| **偶数句押（第 2、4、6 句）** | 自然、呼吸感好 | **推荐**（最常用） |
| 隔句押（第 2、4 句） | 更疏，接近自由诗 | 适合叙事型主歌 |

**奇数句（第 1、3 句）可押可不押** —— 不押反而更活。

### 开口音 / 闭口音的句尾处理

**副歌句尾尽量落在开口音或鼻音上。**

| 句尾类型 | 例 | 效果 |
|---|---|---|
| 开口音 | -a / -ao / -ang | 传得远、好发力、有气势 |
| 鼻音 | -an / -ang / -eng | 有共鸣、余音长 |
| **闭口音** | -i / -u / -ei | 收得住，但**气势弱、传不远** |

> **主歌句尾用闭口音是好的**（收、沉、有味道）；
> **副歌句尾连用闭口音是灾难** —— 高潮部分憋在嘴里出不来。

### 三个听感陷阱（唱出来才知道坏在哪）

| 陷阱 | 表现 | 怎么改 |
|---|---|---|
| **连续同音字** | 咬字含糊，像嘴里含着东西（「四是四」类） | 拆开或换字 |
| **齿音密集** | 喷麦、刺耳 | 一句里齿音字不超过 2 个 |
| **闭口音连收** | 憋气、传不远 | 改句尾或换辙 |

**齿音字清单**（z / c / s / zh / ch / sh / j / q / x）：
```
在 早 字 走 最 曾 从 次 色 三 四 岁
知 这 时 是 事 出 长 少 说 声
几 见 家 起 前 心 想 下 雪
```

> **特别注意「一七辙」** —— 它是齿音最密的一个辙（知/时/事/思/子/词），
> 押这个辙时齿音检查要格外上心。

### 其他硬规则

- **叠字句单独成行** —— AI 唱歌最容易吞叠字（「轻轻」「慢慢」连读就糊了）
- **避免生僻字** —— AI 咬字会崩，字幕难做，观众还认不出

## 四、曲式结构细节

### 三个模板的完整槽位

**模板 A · 短视频标准（推荐）**
```
[副歌核心句]  4 行 × 5~8 字     ← 0:00~0:15，先声夺人
[主歌 A1]     6 行 × 7~12 字    ← 铺场景
[预副歌]      2 行 × 6~10 字    ← 蓄力
[副歌]        4~6 行 × 5~10 字  ← 完整爆发
[主歌 A2]     6 行 × 7~12 字    ← 换角度，不重复 A1
[副歌 ×2]     8~12 行           ← 收尾
```

**模板 B · 标准流行**
```
[主歌 A1]  4~8 行
[预副歌]   2~4 行
[副歌]     4~6 行
[主歌 A2]  4~8 行
[副歌]     4~6 行
[桥段]     2~4 行
[副歌 ×2]  8~12 行
```

**模板 C · 叙事民谣**
```
[主歌 A1]  6~8 行
[主歌 A2]  6~8 行
[副歌]     4 行
[主歌 A3]  6~8 行   ← 故事推进到转折
[副歌]     4 行
[副歌 ×2]  8 行
```

### 各段落职能（别串岗）

| 段落 | 只干这件事 | 常见错误 |
|---|---|---|
| 主歌 | 铺场景、给细节、讲事实 | 主歌里开始抒情 → 副歌没东西可爆发 |
| 预副歌 | 把情绪往上推一格 | 写成第二段主歌 → 蓄力失效 |
| 副歌 | 情绪爆发 + 至少一句钩子 | 副歌里还在讲新信息 → 记不住 |
| 桥段 | 换视角 / 换时空 / 制造转折 | 写成第三段副歌 → 冗余 |

### 时长换算表（100 BPM / 4/4）

| 项 | 值 |
|---|---|
| 1 小节 | 2.4 秒 |
| 1 乐句（4 小节） | ≈9.6 秒 |
| 2 分钟 | 120 秒 ≈ 12.5 乐句 |
| 3 分钟 | 180 秒 ≈ 18.75 乐句 |
| 扣除前奏/间奏/尾奏 | 约 −30 秒（≈3 乐句） |
| **实际唱段** | **≈15~16 个乐句** |
| **折算唱词总量** | **约 120~200 字** |

> **写完先数字数。** 超 250 字的，基本都要砍。
> 不砍的结果是作曲环节被迫砍你的词 —— 而那是在最不该动结构的时候动结构。

## 五、古风 / 国风写词专章

古风写词最容易翻车的不是文笔，是**典故**。

### 典故不能张冠李戴

一次实战研讨中，批评方给出衔接句「醉里偶题纨扇」，创作方当场反驳：

> **「纨扇」是班婕妤《怨歌行》的弃妇意象，安在李白身上是新的张冠李戴。**

批评方本意是夸李白风流，但选的意象自带「失宠被弃」的含义 —— 这就是典型的**意象与人物错配**。

### 常用意象速查表（用错就是硬伤）

| 意象 | 出处 / 含义 | 别用在哪 |
|---|---|---|
| **纨扇 / 团扇** | 班婕妤《怨歌行》→ **弃妇、失宠** | 别用在得意豪放的人物身上 |
| **东风** | 春风、生机 | 与「西风」不要混用 |
| **西风** | 秋风、萧瑟、肃杀 | 别用来写春天 |
| **杨柳 / 折柳** | 送别、挽留 | — |
| **鸿雁 / 雁字** | 书信、思乡 | — |
| **红豆** | 相思（王维《相思》） | — |
| **梧桐** | 凄凉、离愁（李清照「梧桐更兼细雨」） | 别用来写欢愉 |
| **杜鹃 / 子规** | 悲啼、思归 | — |
| **青鸟** | 传信使者（李商隐「青鸟殷勤为探看」） | — |
| **锦瑟** | 李商隐，多义朦胧 | 别硬解成具体含义 |
| **易水** | 诀别（荆轲） | 别用来写重逢 |
| **明月** | 思乡、怀人（最百搭） | — |
| **流水** | 时光流逝、离愁 | — |
| **落花** | 凋零、伤春 | — |
| **南山** | 归隐、长寿（陶渊明） | — |
| **长安** | 功名、都城、繁华 | 注意朝代适配 |

### 古今缝合的语体统一

**古风最常见的事故：前一句还在现代白话里，突然一句文言。**

实录中的真实案例 —— 批评方建议把「屏间休晒体面，杯前莫念从前」加进去，创作方反驳：

> **文言过头 —— 前一句还在"闹钟/地铁/加班"的现代白话里，突然"屏间""杯前"会违和。**

**规则**：整首词的语体必须一致。

| 语体 | 特征 | 混用的后果 |
|---|---|---|
| 纯古风 | 全篇文言化，用典密集 | 观众门槛高，但气质统一 |
| **古今缝合（推荐）** | 现代白话为骨架，古句作点缀 | **要有过渡，不能硬切** |
| 现代白话 | 全篇口语 | 引古句时要让人听出是「引」 |

**缝合技巧**：
- 引古句前后**各留一句做缓冲**，别让古句孤零零插在白话里
- 引古句最好保留原韵（**这条必须写进研讨约束条件**，否则会被当破韵批）
- 现代意象选**全民共享的**（闹钟、地铁、加班、外卖、房贷），别用圈层黑话

### 化用 vs 引用

| 方式 | 做法 | 注意 |
|---|---|---|
| **引用** | 原句照搬 | 最好能让人听出来是引的；公版作品可自由用 |
| **化用** | 改字、拆句、接续 | **不能曲解原意** —— 改完意思反了就是事故 |
| **借意象** | 只用意象不用原句 | 最安全，但要符合该意象的传统含义（看上表） |

## 六、古诗词公版判定

| 情况 | 是否公版 | 说明 |
|---|---|---|
| 唐宋诗词原文 | ✅ 公版 | 作者去世超过保护期（中国：作者死后 50 年） |
| **他人的白话译文** | ❌ 不是 | 译文是独立作品，有著作权 |
| **他人的注解、赏析** | ❌ 不是 | 同上 |
| **他人的改编、谱曲版本** | ❌ 不是 | 改编版有独立著作权 |
| 民国及以后作者的作品 | ⚠️ 需查 | 看作者去世时间是否超 50 年 |
| 现代诗人的作品 | ❌ 不是 | 需授权 |

> **一句话**：**原文是公版，别人对它的加工不是。**
> 用古诗词可以，别顺手把某位学者写的白话译文也搬过来。
