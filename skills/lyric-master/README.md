# 歌词大师一点通

> 你脑子里有一句话，想让它变成一首歌，进而变成一条有人愿意看完的片子。
> **这条线从第一个念头开始，一直走到成片被人看见。**

---

## 为什么写词的人需要一个流程

写歌词的人，真正的卡点往往不是「文笔好不好」，而是这三件事：

1. **不知道写什么** —— 词写得挺美，但没人点开
2. **不知道错在哪** —— 自己改八遍也改不出来，因为一个人看不见自己的盲区
3. **不知道写完怎么办** —— 词被人唱了，署名栏却空着；片子做出来了，发出去没人看

这个技能把这三件事串成一条线。**词是主角** —— 曲子、画面、字幕、成片，都是为了让你的字被人听见、被人看见。

---

## 一条线的两半

```
 ── 词（这是主体）─────────────────────────────
 L1 选题定位        ← 决定「有没有人点开」
      ↓
 L2 曲式骨架        ← 决定「记不记得住」
      ↓
 L3 韵脚与节奏      ← 决定「唱不唱得出」
      ↓
 L4 出稿 ──────────┐
      ↓            │
 L5 双 AI 互批研讨 ─┘  ← 循环 3~4 轮，批评方写「可定稿」，真人终裁
      ↓
 L6 定稿与留证      ← 决定「权利是不是你的」
      ↓
 ── 落地（词从这里开始离开你的手）─────────────
 L7 定稿的去向      ← 交给谁听、卖给谁用、还是先放着
      ↓
 L8 词入声          ← 让字从嘴里出来：曲子怎么出、唱序怎么记
      ↓
 L9 词入画          ← 把句子翻成镜头：意象怎么落成画面
      ↓
 L10 词入轴         ← 让字被看见：字幕怎么呈现
      ↓
 L11 词成片         ← 见人：合成、发布、资产登记
```

**前一半是手艺，后一半是落地。** 写得好只是及格线，**被人听见才算数**。

每一步都用选择题让你选路径 —— **你先选，我才展开**，不铺没用的信息。

---

## 前一半：词是怎么长大的

### 先搭骨架，再填肉

绝大多数歌词写砸的原因，是一上来就从头写到尾 —— 结果必然是主歌冗长、副歌平庸、到桥段已经没话可说。

技能把这一步前置：**先定曲式结构**（附短视频 / 标准流行 / 叙事民谣三种模板），标好每段行数上限，再往槽里填。**填不进去的字就地删。**

顺带解决一个更实际的问题：**短视频时代，副歌核心句必须前置到前 15 秒** —— 完播率决定一切。传统电台逻辑的「主歌先入」在短视频平台上是自杀。

### 让词「唱得出」：十三辙与听感三坑

词意再好，韵脚乱了、字数崩了、齿音堆在一起，唱出来就是一团噪音。

- **十三辙全表** —— 每个辙的韵母、听感、适合放主歌还是副歌
- **字数与乐句对齐** —— 主歌 7~12 字、副歌 5~10 字、钩子句 5~8 字，以及为什么
- **听感三坑** —— 连续同音字（咬字含糊）、齿音密集（喷麦）、闭口音连收（憋气传不远）
- **时长换算** —— 100 BPM 下三分钟 ≈ 15~16 个乐句 ≈ 120~200 字，写完先数字数

写完立刻跑一次自带的**可唱性体检器**，把上面这些一次过一遍。见下方工具箱。

### 双 AI 互批研讨 —— 整条线最值钱的环节

**一个 AI 改自己的稿，改不出东西** —— 它会反复确认自己是对的。
**两个 AI 也不一定有用** —— 不给对立人格，它们会互相吹捧。

所以：

- **AI-1 当创作方** —— 写、改，且必须**逐条回应**批评：接受 / 部分接受 / **反驳**，每条给理由
- **AI-2 当批评方** —— 人格设定为「毒舌批评家」，只挑错，三段式（原句 / 问题 / 改法），禁止空泛评价
- **真人当终裁** —— 一票通过或否决

技能里附了**一次 4 轮收敛的完整实战实录**，含：

- 完整轮次时间线（批 6 条 → 修订 → 批 4 条 → 终稿 → 终审打回 → 修正 → **可定稿**）
- **送审包五件套** —— 尤其是「约束条件」，这是防止 AI 越改越飞的命门（漏了第 4 条，就永远不收敛）
- 高质量批评与**反驳**范例 —— 反驳能抓出单 AI 必漏的三类错误：**覆盖面偏差、典故误用、语体断裂**
- 真人终裁记录模板

> **反驳权是这套流程最值钱的地方。** 别把它当面子问题，它是质量控制环节 —— 实战里批评方自己用错过典故，是创作方反驳时抓出来的。

### AI 味检测清单

一张**大词黑名单** + 一个**结构套话清单**：

```
岁月 时光 流年 青春 红尘 天涯 沧桑 远方 梦想 初心
心灵 灵魂 喧嚣 静好 温柔以待 人间值得 迷失 彷徨 迷茫
```

> 规则很简单：**一首词里这类词不超过 2 个。** 它们不是不能用，是不能连着用 —— 一旦成串出现，整首词就变成了背景音。

配套一句话自测：**把这首词读给你妈听，她能复述出其中的画面吗？**

### 留证与变现：写它为什么能换钱

定稿之后，技能会讲清三件事：

- **认领词曲收益** —— 原唱版分歌曲总收入 **16%**，**翻唱版分 35%**（只要有人唱、有人翻唱，你就永远有一份钱）
- **出售词曲** —— 买断 3,000~50,000 / 授权演唱 1,000~8,000
- **定制词单** —— 当月见现金，确定性最高

**关键提醒**：签约时「作词」栏必须填你自己。空着，等于主动放弃后面所有分成。

也说清哪些路走不通：

- **「区块链上链确权」≠ 版权登记** —— 上链只证明「某时刻你手里有这文件」，不产生著作权、不能对抗第三方
- **公版 ≠ 随便用** —— 古诗词原文是公版，但**别人的注解、白话译文、改编版本**可能不是
- **AI 写的词在权利主张上等于裸奔** —— 用 AI 出草稿可以，但你必须逐句改写，且幅度要够大

## 后一半：落地四事

词定稿了，接下来它要经过四次变形。**每一次都可能把你的字做丢** —— 这四节就是守在四个口子上。

### L8 词入声 —— 听的是「词有没有被吃掉」

同一首词抽 5 版挑 1 是常规操作。但挑什么，大多数人挑错了：**他们在听旋律好不好。**

**你的词才是不可替代的那部分。旋律可以换，字不能被吃掉。** 所以只查三件事：**吃字、改序、重唱尾声**。

**还有一件必须当场做的事**：把「实际唱序」记下来。AI 作曲常常重复或改写尾声 —— 这张纸在 L10 做字幕时值很多时间。

### L9 词入画 —— 把句子翻译成镜头

这一步是「词作者做 MV」和「剪辑师做 MV」最大的分野。核心工具是**意象 → 镜头翻译表**：

| 词里出现的东西 | 画面怎么给 | 别怎么给 |
|---|---|---|
| 具体器物（灯 / 舟 / 窗） | 特写，占画幅三分之一以上 | 远景里一个小点 |
| 时间（三更 / 暮色） | 用光线说，一处道具佐证 | 打在字幕上写「三更」 |
| 情绪（愁 / 念） | 交给一个动作，或空镜承接 | 让人对着镜头做表情 |
| 人群（世人 / 谁） | 剪影、背影、只给局部 | 群演正脸 |

> **一句话原则**：词里写具体的，画面就给具体的；词里写虚的，画面要给实的接住。

同一个意象还有**写实 / 写意 / 抽象**三个档位 —— 一档走到底，别混着来。

### L10 词入轴 —— 字幕是词的第二次生命

**有人听不清唱什么，但字幕会替你说完。** 词作者在这一步的收益，比在其他任何一步都直接。

- 三种形态：**整句 / 卡拉OK 逐字 / 词卡**（推荐的组合是主歌整句 + 副歌逐字 + 金句词卡）
- **唱序 ≠ 写序** —— 字幕必须按 L8 记下的实际唱序拆条。贴错的后果不是难看，是**观众会以为你写错了词**
- 可读性硬指标：字号 ≥ 画面高度 1/12、每行 ≤14 字、字比声音早 0.1~0.2 秒出现

### L11 词成片 —— 见人

合成是一页步骤的力气活；真正拉开差距的是**发布**：标题怎么起（用 L1 的钩子公式反填）、封面给哪一帧、文案前两行写什么。

最后是**资产登记** —— 词、曲、片、数据、署名，五样齐了，你才算从「写了一首歌」变成「攒了一份资产」。

## 工具箱

**两个零依赖脚本**（Python 标准库，不用装任何东西）：

**1. 双 AI 研讨引擎**（L5）—— 一条命令跑完整套研讨：

```
1. 复制 scripts/config.example.json 为 config.json，填主题和目标受众
2. 运行 python scripts/dual_ai_review.py
3. 在输出目录里拿：每轮稿件 + 批评意见 + 研讨纪要 + 真人终裁记录空表
```

| 模式 | 需要什么 | 干什么 |
|---|---|---|
| **全自动** | 两个 OpenAI 兼容接口的 Key | 起草 → 送审 → 回应改稿 → 复审，自动往返 N 轮，批到「可定稿」为止，每轮落盘 |
| **半自动** | **什么都不用** | 引擎只生成每轮提示词，你复制到两个网页 AI 里粘贴 |

没填 Key 会自动降级，不会报错卡住。国内主流平台（DeepSeek / 火山方舟 / 通义 / Kimi / 智谱 / 硅基流动）的接口地址已内置速查表。

**收敛信号是批评方白纸黑字的「可定稿」三个字**，不是「感觉差不多了」。最后一步（分歧项裁定）**必须由真人做**。

**2. 可唱性体检器**（L3 / L4）—— 写完立刻跑：

```
python scripts/sing_check.py "词稿.txt"
```

跑完得到 `可唱性体检报告.html`：

- **末字辙口表** —— 把每段末字竖着排成一列，**能一眼读出节奏的，就是押上了**
- **听感三项** —— 齿音密度、句尾闭口音、叠字
- **AI 味筛查** —— 大词命中、字数异类句、总字数区间
- **体检清单** —— 每条都带具体改法

> 这份清单本身，就是 L5 送给批评方的一份**可量化的约束条件** —— 直接省掉一轮来回。

## 适用场景

- 古诗词新唱、国风歌词创作
- 文化类账号的内容写词
- **企业宣传曲、景区主题曲、家乡形象曲**的词作
- 寿宴 / 婚礼 / 纪念曲等定制词单
- 已有歌词想找人「挑毛病」，但身边没有专业审稿人
- **想把一首词真正做出来、发出去的人** —— 从 L8 开始就是给你准备的
