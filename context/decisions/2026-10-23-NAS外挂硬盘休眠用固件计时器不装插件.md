# 决策：NAS 外挂硬盘休眠用固件计时器，不装插件

**结论**：用 `hdparm -S` 把空闲计时器写进硬盘，再用 `/etc/rc.local` 固化。
**不装 hd-idle，不装任何休眠插件，不加常驻服务。**

## 背景

iStoreOS 上一块 WD Elements 2.8TB 外置盘（ext4，`/dev/sdc`），通过 SMB 当游戏/文件库用。
用户先后装、又卸了应用中心的「硬盘休眠」插件，想知道休眠时间怎么调长。

同时有个矛盾现象：这块盘**通电将近一年**，但 SMART 显示 `Power_On_Hours` 只有 **734 小时**。

## 诊断过程（关键点）

**1. 先分清两个工具，别混用**

| | `hdparm -S` | `hd-idle` |
|---|---|---|
| 机制 | 把计时器写进盘（ATA `IDLE` 命令） | 后台服务计时，到点发 SCSI `START_STOP` |
| 持久性 | 掉电可能丢 | 服务停了就没 |
| USB 盒子兼容 | 要求透传 ATA，老盒常失败 | 兼容率更高 |
| **能否把时间调长** | **能** | **不能，只能催睡** |

→ 用户的诉求是"调长"，**`hd-idle` 方向上就做不到**。这是最关键的一步：
插件不是配置错了，而是**它根本不是干这事的工具**。

**2. 实测盒子是否透传**

`hdparm -S 244 /dev/sdc` 返回成功。这一步是分水岭 —— 失败就只能退回 `hd-idle`（且无法调长）。

**3. 确认没有东西在偷写**

- 60 秒进程级快照（`/proc/[pid]/io` 差分）：零
- 内核侧 `/proc/diskstats` 10 秒：读 0 / 写 0
- 强制 `hdparm -y` 后 **第 2 秒进 standby，60 秒内没被吵醒**

三项全绿 → 不需要排查 `ext4lazyinit`、`atime`、`smartd`、SMB 保活这些常见元凶。

**4. 解开 734 小时的矛盾**

`734 / 8760 = 8.4%`，即这块盘 **91.6% 的时间在 standby**，而 SMART 通电计时在 standby 时不走。
"通电一年" 与 "734 小时" **完全不矛盾**。

反过来还证明了：**这块盘出厂自带的空闲休眠一直在生效**，用户装插件纯属画蛇添足。

> 教训：看到 `Power_On_Hours` 偏低，不要立刻判"盘很新"。
> 先算 `小时数 / 装机时长`，比例低说明它在睡觉，不是它没用过。

## 选项对比

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| `luci-app-hd-idle` 插件 | 有图形界面 | 只能催睡、无法调长；多一个常驻服务 | 放弃，已卸载 |
| 手写 `hd-idle` 配置 | 比插件轻 | 同上，方向不对 | 放弃 |
| **`hdparm -S` + `rc.local`** | 零常驻服务、断电语义清晰、可调任意长度 | 掉电可能丢，必须固化 | **采用** |
| 什么都不做 | 省事 | 计时器是出厂默认，不可控 | 放弃 |

## 实施要点

- **换算**：`-S 244` = `(244-240)×30` = 120 分钟。1–240 是 5 秒倍数，241–251 是 30 分钟倍数。
- **固化位置**：`/etc/rc.local`，块必须在 `exit 0` **之前**。
- **按型号匹配，不要按 `sdX`**：插拔后设备名会变，写死 `sdc` 开机即失效。
  ```sh
  for _d in /sys/block/sd*; do
      grep -qi elements "$_d/device/model" 2>/dev/null || continue
      /sbin/hdparm -S 244 "/dev/${_d##*/}" 2>/dev/null
  done
  ```
- **值设多少**：按使用频度定。偶尔用 → 120~240 分钟；天天频繁用 → 设 `0` 一直转。
  设 5~10 分钟几乎必然是错的，会被 SMB 浏览和缩略图反复吵醒。
- **无法验证设置值**：`hdparm` 没有读 `-S` 的选项，只能静置后听停转 / 摸温度 / 看功率计。

## 一个必须记住的坑：终端乱码不等于文件坏了

在 Windows `cmd` 里通过 `ssh` 跑 Linux 脚本时：

- `scp` 执行后**会改动控制台代码页**，导致后续 GBK/UTF-8 中文全变 `◆◆◆`
- 但把输出**重定向进文件**就完全正常

→ 正确做法是 `ssh host "sh script.sh" > out.txt 2>&1`，读文件；
不要去"修"那个乱码，会越修越错（改文件编码反而把脚本改坏）。

另外 `.bat` 里含中文必须存 **GBK + CRLF**。UTF-8 + `chcp 65001` 会让 cmd
**解析错位**，把半行中文当命令执行（报 `'xxx' is not recognized`）。

## 可逆性

- **完全可逆**：`set_sleep.sh 0` 关掉自动休眠；删掉 `rc.local` 里的 `SETSLEEP` 块即恢复原状。
  块有唯一标记，删改不会误伤其他内容，脚本还会自动备份成 `rc.local.bak.<时间戳>`。
- **重新评估信号**：
  - 换成不支持 ATA 透传的硬盘盒 → `hdparm -S` 会失败，只能退 `hd-idle`（且放弃"调长"）
  - 盘改成频繁访问（如做下载盘/媒体库实时索引）→ 应改成 `0` 一直转
  - 需要精确控制启停次数 → 装 `smartmontools` 看 Attribute 4 / 12
