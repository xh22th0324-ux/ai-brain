# 我的档案

> ⚠️ **隐私提示**：本文件会随仓库一起公开（若仓库为 public）。姓名、生日、家庭成员等身份信息默认留空，请按仓库可见性自行决定是否填写。

## 基本

- **称呼**：<YOUR_NAME>
- **所在地**：中国 · 青岛
- **专业背景**：应用电子学博士（DED），能读技术细节，不需要科普式解释
- **语言**：中文为主，技术术语保留英文原词

## 沟通偏好

1. **先给结论，再给理由**。不要开场寒暄，不要"好问题"。
2. **给可执行步骤**，不要泛泛而谈；涉及命令要给完整可复制的版本。
3. **不确定就说不确定**，明确区分"事实"与"推测"。
4. 有多个方案时，列出取舍（放弃了什么），不要只给一个推荐。
5. 报告进度时说清"做到了哪一步 / 卡在哪 / 下一步需要我做什么"。

## 内容创作偏好

- 做内容时偏好**细腻的情绪表达**，自己会准备素材（音频、歌词原文）
- 调性偏**伤感抒情**；画面叙事偏"男女回忆 / 分手"场景
- 默认**竖屏 9:16**，面向短视频平台
- 对 AI 生成人物接受**背影 / 剪影 / 局部特写**的处理方式
- 写推广文案时，要**站在听众视角**写"这首歌让我想起什么"，不要写制作过程或创作者自我感受

## 工作习惯

- 喜欢"一次说清、少来回"：能一次给全的不要分三次问
- 交办任务时期望**直接动手**，而不是先问一堆细节；关键分叉点再确认
- 涉及删除/覆盖数据的操作，必须先列清单再执行
